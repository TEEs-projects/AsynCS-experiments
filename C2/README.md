# C2 placement and size grid

Includes accepted core sources for AsynCS round 340, Native round 351, and
Reusable round 360. The AsynCS 16 MiB supplement is materialized from its
explicit public-prepared manifest. Reusable 16 MiB groups 6-17 are included as
accepted public-safe child derivatives.

Public ciphertext payloads are included where authorized by the prepared-public
manifests. Private verifiers, `skU`, protected authority state, and raw
activation archives remain excluded.
